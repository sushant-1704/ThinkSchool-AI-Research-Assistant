# 📚 Think School AI Research Assistant

An AI-powered Research Assistant built using Retrieval-Augmented Generation (RAG) to help analyze Annual Reports, DRHPs, Research Papers, and Business Documents.

---

## Features

- 📄 Upload PDF Documents
- 💬 Chat with Documents
- 📚 Source References
- 📊 Executive Summary
- 🏢 Business Model
- 💰 Revenue Streams
- 📈 Growth Opportunities
- ⚠️ Risk Analysis
- 🤝 Competitor Analysis

---

## Tech Stack

- Python
- Streamlit
- LangChain
- OpenAI
- FAISS
- PyPDF

---

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
